# Live Translate v4 (offline, tanpa API)

- Menangkap suara internal HP (Android 10+), tanpa mikrofon.
- Pengenalan bahasa Inggris offline: Vosk model lgraph (~130 MB, lebih akurat dari model kecil).
- Terjemahan Indonesia offline: ML Kit (model ~30 MB).
- Internet hanya dibutuhkan sekali untuk mengunduh model.

Build: unggah isi folder ke GitHub, tab Actions membuat app-debug.apk.
